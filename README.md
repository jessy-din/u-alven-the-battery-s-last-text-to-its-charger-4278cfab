A program that writes a phone battery's last text message to the charger it waited for all day — one funny line to `/output/entry.txt`.

> You left me at 1% again. I held on all day out of love, and you repaid me by Googling 'is it bad to charge overnight'.

## Run it

```sh
node main.ts
```
